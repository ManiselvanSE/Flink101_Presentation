# Apache Flink 101 Presentation

A presentation deck for an introductory walkthrough of Apache Flink.

## Presentation

- [Open the Flink 101 presentation (PDF)](Flink_presentation.pdf)

## Suggested use

Use the deck as an introduction, then reinforce the concepts with a hands-on streaming exercise. For a practical learning path, cover:

1. Stream processing versus batch processing.
2. Flink jobs, operators, parallelism, and execution graphs.
3. Event time, timestamps, and watermarks.
4. Stateful processing, checkpoints, and recovery.
5. Joins and handling late-arriving events.
6. Observability, backpressure, and production troubleshooting.

## Notes

- This repository currently contains the PDF deck; it is a presentation resource rather than an executable lab.
- Check the Apache Flink documentation for version-specific details and current APIs before using examples in production.
